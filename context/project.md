# Contexto del proyecto

## Propósito conocido

`retomariposa` es una prueba de concepto de un reto para parejas de 30 días. Cada integrante participa desde su propio dispositivo y raspa una tarjeta para descubrir el mismo reto del día, con una experiencia emocionante inspirada en los juegos de raspar.

## Alcance y requisitos

Se busca una interfaz web sencilla en HTML, adaptable a móviles, moderna y cuidada, con colores rosas e iconos de mariposa. La intención es publicar la prueba de concepto.

Consulta los [requisitos](./requirements.md) para conocer los criterios y las decisiones que aún necesitan confirmación.

## Estado

Existe una prueba de concepto web estática. Los textos de los retos son propuestas pendientes de revisión y aún no se ha definido el entorno de publicación.
