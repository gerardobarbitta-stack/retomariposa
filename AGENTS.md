# Instrucciones para agentes

## Antes de cambiar código

- Lee `README.md` y el contexto relevante en `context/`.
- Inspecciona la estructura y las convenciones existentes antes de elegir herramientas o patrones.
- No supongas un stack, requisitos de producto ni comportamiento que no estén documentados o confirmados en el código.

## Durante el trabajo

- Mantén los cambios enfocados en la solicitud y respeta las convenciones existentes.
- Si un requisito importante es ambiguo y no puede resolverse desde el repositorio, pregunta antes de tomar una decisión que afecte el comportamiento.
- No incluyas secretos ni datos sensibles.
- Actualiza el contexto cuando un cambio modifique de forma duradera el producto, la arquitectura o una decisión documentada.

## Al terminar

- Ejecuta las pruebas, validaciones o comprobaciones relevantes que admita el proyecto.
- Informa qué cambió y qué validaciones se ejecutaron; indica claramente cualquier validación que no pudo ejecutarse.
- Usa las skills de `.github/skills/` cuando correspondan a la tarea.
